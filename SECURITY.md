# Security policy

Report a vulnerability privately through [GitHub security advisories](https://github.com/darshansatpathy/agent-memory-service/security/advisories/new). Please do not open a public issue. You can expect a first reply within five working days.

## In scope

- Reading, changing or erasing another tenant's memories, through the API or by any query path.
- Personal data of a blocked or scrubbed kind reaching the database, logs, metrics or error responses.
- Expired or erased memories being returned.
- API key handling: keys are shown once and stored only as SHA-256 hashes.

## Supported versions

The latest release receives fixes.
